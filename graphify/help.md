
### 📂 نحوه استفاده از فایل‌های خروجی

| فایل | سناریوی مناسب | نحوه استفاده |
| :--- | :--- | :--- |
| **`GRAPH_REPORT.md`** | ابتدا نمای کلی را ببینید | مستقیم به ایجنت بدهید تا به‌سرعت مفاهیم اصلی، ارتباطات غیرمنتظره و سوالات پیشنهادی پروژه را درک کند . |
| **`graph.json`** | زمانی که ایجنت به قابلیت پرس‌وجوی ساختاریافته نیاز دارد | **آن را مستقیم paste نکنید**. به ایجنت بگویید از دستور `graphify query` برای استخراج زیرگراف مرتبط استفاده کند، یا از MCP server برای اتصال استفاده کنید . |
| **`graph.html`** | خودتان می‌خواهید به‌صورت بصری بررسی کنید | در مرورگر باز کنید، به ایجنت ندهید. |

### 💡 دو روش عملی

**روش اول: استفاده از دستور پرس‌وجو برای استخراج خروجی متمرکز (توصیه می‌شود)**

مستقیماً به ایجنت بگویید ابتدا دستور را اجرا کند و نتیجه را دریافت کند، سپس بر اساس نتیجه به سوال پاسخ دهد. مثلاً:

```bash
graphify query "جریان احراز هویت چگونه کار می‌کند" --graph graphify-out/graph.json
```

خروجی شامل برچسب گره‌ها، انواع یال‌ها، برچسب‌های اطمینان، فایل‌های منبع و موقعیت‌ها است و بسیار مناسب است که به‌عنوان «بلوک زمینه» به ایجنت داده شود . به ایجنت بگویید: «از این خروجی زیرگراف برای پاسخ به سوال استفاده کن، تا حد امکان فایل‌های منبع را ذکر کن».

**روش دوم: استفاده از MCP Server (مناسب برای پرس‌وجوهای مکرر)**

اگر دستیار شما از MCP پشتیبانی می‌کند، `graph.json` را به‌عنوان سرور MCP بالا بیاورید:

```bash
python -m graphify.serve graphify-out/graph.json
```

ایجنت از طریق ابزارهایی مانند `query_graph`، `get_node`، `shortest_path` و غیره به‌طور ساختاریافته به گراف دسترسی پیدا می‌کند و دیگر نیازی به paste دستی متن نیست .
